# Halloween Vision & Visitor Analysis

**🎃Project Overview**

This project focuses on analyzing Halloween visitor data using Tableau. The dashboard presents visitor trends, patterns, and key insights through interactive and easy-to-understand visualizations. It helps users explore the data and understand visitor behavior across different periods.

**📊 Dashboard Features**
- Interactive Tableau dashboard
- Visitor trend analysis
- Year-wise visitor comparison
- Average visitor analysis
- Interactive filters for exploring the data
- Easy-to-understand charts and visualizations
- Clear presentation of important visitor insights.

**🔍 Key Insights**
- Identified visitor trends across different years.
- Compared visitor performance over different periods.
- Analyzed average visitor patterns.
- Highlighted changes and variations in visitor numbers.
- Provided a clear visual understanding of Halloween visitor trends.

**🛠️ Tools Used**
- Tableau
- Data Visualization
- Data Analysis
- Tableau Filters and Interactive Dashboards.

**🎯 Project Objective**
The main objective of this project is to analyze Halloween visitor data and present meaningful insights through an interactive Tableau dashboard. The project aims to make visitor trends and patterns easier to understand using effective data visualization techniques.

# Bank Customer Churn Ananysis Dashboard

**📌 Project Overview**

This project focuses on analyzing bank customer churn using Tableau. The dashboard provides a clear view of customer characteristics, churn patterns, and important factors associated with customer attrition. Interactive visualizations help users explore the data and understand customer churn behavior.

**📊 Dashboard Features**
* Interactive Tableau dashboard
* Customer churn analysis
* Churn rate visualization
* Customer demographic analysis
* Analysis based on gender, age, country, and active membership
* Customer balance and credit score analysis
* Interactive filters for detailed exploration
* Easy-to-understand charts and visualizations

**🔍 Key Insights**
* Identified patterns among customers who have churned and remained with the bank.
* Compared churn across different countries and customer groups.
* Analyzed the relationship between customer age and churn.
* Examined churn patterns based on active membership and gender.
* Explored customer balance and credit score in relation to churn.

**🛠️ Tools Used**
* Tableau
* Data Visualization
* Data Analysis
* Interactive Dashboard
* Filters and Charts

**🎯 Project Objective**
The main objective of this project is to analyze bank customer churn and identify patterns that may influence customer retention. The dashboard aims to provide meaningful insights through interactive data visualizations, helping users better understand customer behavior and churn trends.
